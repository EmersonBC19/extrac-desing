Permitir que Code to Figma descargue imágenes

Para copiar a Figma las imágenes de una página (fotos, logos, iconos alojados en otros dominios), la extensión necesita permiso para descargarlas. Sin él, esas imágenes llegan vacías.

Solo se descargan las imágenes del componente que envías, en el instante en que lo envías. No se lee ni se envía nada más.
